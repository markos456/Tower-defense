# Hamlet TD — PSP

Порт браузерной игры Hamlet (Tower Defense) на PSP. Язык: C + PSPSDK. Сборка — через GitHub Actions.

## Как собрать через GitHub
1. Создай репозиторий на GitHub и залей туда все файлы этой папки (включая `.github`).
2. Открой вкладку **Actions** → запустится сборка *Build PSP EBOOT* (или нажми **Run workflow**).
3. Когда она станет зелёной, открой её и скачай артефакт **HamletTD-PSP**.
4. Распакуй и скопируй папку `PSP` на карту памяти (получится `PSP/GAME/HamletTD/EBOOT.PBP`).
5. Запусти на PSP (в разделе «Игра» → «Карта памяти») или в эмуляторе PPSSPP.

## Управление (этап 1)
- Крестовина — курсор по клеткам
- **X** — поставить башню (125 монет)
- **R** — улучшить башню под курсором, **L+R** — прокачать на максимум
- **Квадрат** — продать, **Треугольник** — скорость 1x/2x/3x, **Start** — пауза / рестарт после проигрыша

## Что уже есть
Поле 18x16, дорога карты «Змейка», волны, зомби дают 1–5 монет, башня-стрелок, бесконечные улучшения,
